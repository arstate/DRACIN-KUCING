## 🎯 CARA INPUT KE NANO BANANA 2.1:
1. Buka Nano Banana 2.1.
2. Upload gambar referensi di atas ke kolom **Image Reference / Image Input**.
3. Atur bobot referensi:
   * Latar Pesta: `~0.85`
   * Karakter Oyen & Molly: `~0.90`
4. Copy-paste prompt dari berkas [`03_PROMPT_MASTER_SCENE_01.md`](../03_PROMPT_MASTER_SCENE_01.md).
5. Simpan hasil generate ke folder: `S1_EPS_01/SCENE_01/HASIL_GEN_MASTER/S1_SCENE_01_MASTER.png`.
